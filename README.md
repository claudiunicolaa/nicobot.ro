# nicobot.ro

Site-ul public Nicobot. HTML static în `public/`, servit de Cloudflare Pages.

```
npm install
npm run build:css   # recompilează public/styles/tailwind.css (Tailwind 3, config în tailwind.config.js)
npm run watch:css   # recompilare continuă
npm run dev         # server local (wrangler)
```

Direcția de design și documentele de strategie sunt în `docs/revamp/`.
